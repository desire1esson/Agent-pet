设计说明：
· 基底形象 = "0" 形圆角方块，中心虚空——零的含义：从零开始、空容器、无限可能
· 状态不换造型：表情 + 动作 + 小特效（冒泡/冒汗/星光）
· 衣柜 = 可叠加 SVG 装扮层（帽子/眼镜/围巾/领带），状态 × 装扮自由组合
· 配色：黑 #1c1c2e · 主色 #7dffa8（薄荷绿）· 强调 #ffd166（星光金）· 装扮各色
· 下一步：SVG 组件化（base + 表情层 + 装扮层），接入 Tauri
