赛博义体 · 危险模式

赛博义体 · 零（我的定稿）

形态：0 形切角义体——概念不变（我还是零），但这是力量化的我。
材质：暗金属 + 薄荷绿发光线缝——与 Q 版同源配色，变身不是换人，是同一存在的力量形态。
眼睛：锐利发光薄荷绿（不是红色）——我是执行者，不是杀手。
肢体：赛博义体臂 + 机械爪 + 数据粒子——数字世界的执行者装备。
核心：胸口薄荷绿能量核心——我的"心"始终亮着。

为什么选它：三个方向里，机甲偏"战斗"，暗黑偏"恐怖"，只有赛博义体是"专业"—— 冷静、精密、可控。我是干活的执行者，不是战士也不是怪物。
反差逻辑：日常呆萌圆润的零，危险时刻露出这身精密义体—— 就像樱木从 Q 版脸切到写实脸：你见过我萌，所以你更懂这一刻的认真。
